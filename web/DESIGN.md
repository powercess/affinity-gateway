# Affinity Console design

定位：网关只读开发者控制台。优先展示可追溯的观测证据，而非营销内容。

参考本地 awesome-design-md skill 中 Linear 的设计分析（上游快照 `8147538b4226ae41e2487a9179e3bcc1f68e8554`，https://github.com/voltagent/awesome-design-md）。只借鉴细边框、分层表面、克制强调色；不复制品牌、专有字体、营销布局或只支持深色的限制。

- 左侧导航 / 中间工作区 / 右侧详情。窄屏导航移至顶部，详情全屏，数据表局部横向滚动。
- 默认跟随系统明暗主题，用户选择仅存本地。中性冷灰背景，靛蓝用于链接和焦点；绿表示成功，红表示拒绝或错误，中性色表示未知。
- 正文与常用控件 14px，标题 28px；12px 用于辅助信息。ID、头部、路径、耗时用系统等宽字体。不请求外部字体或图片。
- 4px 间距基准；面板 8px 圆角、1px 边框、无装饰阴影。保持键盘焦点、文本状态、语义表格及可关闭模态详情。
- 图表与指标由同一数据集派生；颜色之外保留文字说明。数据没有出口证据时显示未知，不显示绿色完成路径。
- 顶栏仅保留一个“演示数据”标记，悬停可查看数据来源。不要重复放置只读、脱敏、架构边界等宣言；实现限制写入文档，页面保留字段值、操作和具体错误。没有修改配置、删除绑定、伪造实时连接等动作。
